4.3 Technical Challenges & Engineering Solutions

  1. Challenge 1: Web-Incompatible HEIC Image Format: The source image (IMG_9169.heic) was unreadable by web browsers.
    Solution: Developed a WebAssembly conversion pipeline using heic-convert to extract high-resolution, web-standard JPEG (398 KB) and PNG assets in public/.
  2. Challenge 2: Shared Shell & Zero-FOUC Theme Initialization: Preventing navigation re-renders and dark mode flash on page transitions.
    Solution: Refactored the architecture into Next.js App Router root layout (app/layout.tsx) embedding a shared glassmorphic header, persistent ThemeProvider, and an inline head script.

4.4 Design Choice Justifications & Future Scope

Justification: Semantic HTML5 tags were chosen over generic containers to ensure search engine indexability (SEO) and screen reader accessibility (WCAG 2.1). Next.js App Router was chosen for static pre-rendering, instantaneous page loads, and native asset delivery.

Future Scope: Connect the contact form to a live serverless backend (Resend API / Node.js) for automated email delivery, store submissions in a PostgreSQL database, and implement automated CI/CD with GitHub Actions.
