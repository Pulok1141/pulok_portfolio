# Mahmudul Hasan Pulok - Personal Portfolio

A personal portfolio website for **Mahmudul Hasan Pulok**, Computer Science & Engineering Student at Daffodil International University. Engineered with **React**, **Next.js 14 (App Router)**, **Tailwind CSS**, and **Framer Motion**.

---

## 🌟 Features

- **Minimalist & Modern Aesthetic:** High-end glassmorphism design with responsive dark/light mode toggle.
- **Fluid Micro-Animations:** Staggered viewport scroll reveals powered by Framer Motion.
- **Engineered Sections:**
  - **Hero:** Profile overview, live status badge, and direct call-to-actions.
  - **About:** Comprehensive engineering background and core technical pillars.
  - **Skills:** Categorized pill badges (Core, Frontend & UI, Data Science & ML, Tools & Graphics).
  - **Projects:** Responsive 3-column card grid with stack tags and repository links:
    - *Automated Tour Budget Engine* (LightGBM, Optuna, Scikit-Learn)
    - *AsyncGraph* (React, TypeScript, Vite, Figma)
    - *RoadPulse* (C, OpenGL)
  - **Contact:** Interactive message form and direct verified links (Email, LinkedIn, GitHub).

---

## 🚀 Local Development

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build

# Start production server
npm run start
```

## 🌐 Free Permanent Deployment (Vercel)

This project is configured out-of-the-box for **Vercel** (the creators of Next.js):
1. Push this repository to your GitHub account (`Pulok1141`).
2. Log in to [vercel.com](https://vercel.com) using your GitHub account.
3. Click **"Add New..."** > **"Project"** and select this repository.
4. Click **"Deploy"**. Vercel will build and provide your permanent public URL (e.g. `https://mahmudul-hasan-pulok.vercel.app`).
